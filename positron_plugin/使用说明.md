# Positron 插件使用说明

这个目录是正式插件目录，以后优先使用这里，不再使用旧的 `pluige` 目录。

## 安装到 Positron

```powershell
cd C:\Users\Administrator\Desktop\qmdtool\mybooksystem\positron_plugin
positron --install-extension .\qmdtool-positron-0.1.0.vsix --force
```

安装后重启或 Reload Positron，然后在普通窗口里使用：

```text
QmdTool: Convert & Preview
QmdTool: Preview HTML
QmdTool: Preview PDF
QmdTool: Render HTML
QmdTool: Render PDF
```

## 重新打包

```powershell
cd C:\Users\Administrator\Desktop\qmdtool\mybooksystem\positron_plugin
npm install
npm run package
```

打包后会生成：

```text
qmdtool-positron-0.1.0.vsix
```

如果不再打包，可以删除 `node_modules`，不影响已生成的 VSIX。
